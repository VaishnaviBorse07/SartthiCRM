FAQ

Common questions.

Does the compliance calendar update automatically?
+
Yes. All statutory due dates (GST, TDS, ROC, FEMA) are pre-loaded and update each financial year automatically. You can also add custom deadlines per client.
Can I bulk-send WhatsApp reminders to all clients?
+
Yes. Select all clients with a specific upcoming deadline and send a bulk WhatsApp message via Interakt. You can customize the message template per deadline type.
Is client data kept confidential?
+
Absolutely. Each CA firm's data is fully isolated. Documents on R2 storage are encrypted. Staff can only access clients assigned to them unless given admin rights.
